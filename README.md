# Tic-Tac-Toe

A two-player tic-tac-toe game for the terminal. Players take turns placing **X** and **O** on a 3×3 board. Prompts and messages are in Hebrew.

## Requirements

- Python 3

No extra packages are required.

## How to run

```bash
python tictactoe.py
```

## How to play

1. The board starts numbered 1 through 9.
2. Player **X** goes first. Enter a number from 1 to 9 to claim that square.
3. Players alternate until someone wins or the board is full.
4. Type `exit` at any prompt to quit.

A player wins by filling a row, column, or diagonal with their mark. If every square is filled and neither player has a line, the game is a draw.
